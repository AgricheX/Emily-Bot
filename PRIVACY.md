# Privacy Policy — Emily (ChatRealms bot)

Last updated: 2026-10-18

## English

**What the bot stores.** For each server that uses it: the server ID, its settings (unit mode, destructive actions, wars, point regeneration and maximum, announcement channel) and the pairing code. For each member who uses commands: the Discord user ID, the kingdom they joined, the unit they control and their action points.

**What the bot does not store or read.** It does not read message content, DMs, or any data beyond the slash commands sent to it. It does not store usernames, avatars or emails.

**What is sent to the game.** To run an action, the bot sends the game owner's mod your Discord user ID, display name, the chosen kingdom, and the action and its parameters (for example the text of a unit speech command). The mod owner can see this information.

**Where data is kept.** In a file on the server that runs the bot. It is not sold or shared with third parties, and it is used only to run the bot.

**Retention and deletion.** Data is kept while the bot is in use. Server administrators can erase their pairing code with the revoke command. To delete your data, contact the address below and include your Discord user ID.

**Contact.** discord.gg/s3EbgNSsJW

## Português

**O que o bot guarda.** Para cada servidor que o usa: o ID do servidor, as configurações (modo de unidades, ações destrutivas, guerras, regeneração e máximo de pontos, canal de avisos) e o código de pareamento. Para cada membro que usa comandos: o ID de usuário do Discord, o reino em que entrou, a unidade que controla e seus pontos de ação.

**O que o bot não guarda nem lê.** Não lê o conteúdo de mensagens, mensagens diretas nem dados além dos comandos de barra enviados a ele. Não guarda nomes de usuário, avatares nem e-mails.

**O que é enviado ao jogo.** Para executar uma ação, o bot envia ao mod do dono do jogo o seu ID de usuário do Discord, o nome de exibição, o reino escolhido, a ação e seus parâmetros (por exemplo o texto do comando de fala da unidade). O dono do mod pode ver essas informações.

**Onde os dados ficam.** Em um arquivo no servidor que roda o bot. Não são vendidos nem compartilhados com terceiros e são usados apenas para o funcionamento do bot.

**Retenção e exclusão.** Os dados são mantidos enquanto o bot estiver em uso. Administradores podem apagar o código de pareamento com o comando de revogar. Para apagar seus dados, entre em contato pelo endereço abaixo informando o seu ID de usuário do Discord.

**Contato.** discord.gg/s3EbgNSsJW
